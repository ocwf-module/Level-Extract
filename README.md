# Level Extract

\[Level_Extract.exe\] — это программа для извлечения и обработки файлов из архивов уровней \[level.pak\] игр на движке CryEngine 3, а также корректной обработки файлов, полученных при помощи [NUX_MOD_SDK](https://nux.re/), для получения файлов и данных, необходимых для сборки \[.cry\] файла уровня.

## Для работы программы требуется:
- Расшифрованные архивы уровня \[level.pak\] и \[terraintexture.pak\];
- Папка \[EntityArchetypes\], которая расположена в клиенте игры/движка в папке \[Libs\]. Она необходима для корректного извлечения сущностей \[EntityArchetypes\], а следовательно, папка должна быть взята из того клиента, который будет использоваться в SandBox при последующей сборке уровня, но при этом клиент не должен быть младше по возрасту, чем сама карта, иначе сущности примут пустой GUID, так как необходимых сущностей в библиотеке может просто не оказаться;
- Папка \[NUX_MOD_SDK\], в которой должны находится файлы из папки \[Layers\] уровня, который был открыт и обработан в [NUX_MOD_SDK](https://nux.re/). Если, конечно, вам нужно извлечь такие элементы уровня как \[Brush\], \[Road\], \[WaterVolume\], \[Vegetation\] и \[Terrain Block\] (в процессе выполнения программы вы можете от этого отказаться).

**Это всё должно лежать в одной директории с программой!**

## Как она работает?

После того как все требования выше выполнены, вы можете запустить программу, и она начнёт выполнение (как я уже сказал выше, программа в процессе попросит согласится или отказаться в запуске процесса обработки файлов, полученных из [NUX_MOD_SDK](https://nux.re/), введите 1 или 0 соответственно).
